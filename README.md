# MINORITY CLUB — 14명 실시간 플레이 완성본

로그인 없이 닉네임만으로 2~14명이 동일한 방에 참여할 수 있습니다. 방장이 초대 링크를 공유하고 게임을 시작합니다. 모바일 UI, 10초 투표, 10라운드, 중간 랜덤 2배 2회 + 마지막 2배, 실시간 순위가 구현되어 있습니다.

## 로컬 실행
Node.js 18 이상에서 `npm start` 실행 후 `http://localhost:3000` 접속. 별도 패키지 설치 불필요. `npm test`로 다중 접속 API 검증.

## 클로드 배포 요청
이 ZIP의 소스는 서버까지 구현 완료되었습니다. 코드를 변경하지 말고 GitHub 저장소에 업로드한 후 **Node.js 서버가 실행되는 호스팅(Render/Railway 등)**에 연결해 배포하세요. 시작 명령은 `npm start`, 포트는 `process.env.PORT`를 사용합니다. 배포 후 HTTPS URL을 공유하세요.

**주의:** GitHub Pages는 정적 HTML만 제공하므로 실시간 멀티플레이 서버를 실행할 수 없습니다. GitHub는 코드 저장소로 사용하고 Node 서버 호스팅이 별도로 필요합니다. 서버가 재시작되면 진행 중인 방이 초기화됩니다. 한 서버 인스턴스 기준으로 작동하며, 무료 호스팅은 슬립/재시작이 발생할 수 있으므로 게임 중에는 항상 켜진 단일 인스턴스를 사용하세요.

## 기능
- 방 생성, 6자리 코드 입장, 초대 링크 입장, 14명 제한, 중복 닉네임 방지
- 방장 권한, 자동 라운드 진행, 투표 중 선택 비공개, 결과 및 순위 동기화
- 서버에서 시간/점수 계산, 임의 점수 조작 방지, 재접속 시 세션 복구(같은 탭)
- 1인 체험 모드도 유지
